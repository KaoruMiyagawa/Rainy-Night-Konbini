# 开发路线图

以下条目是后续候选工作，尚未包含在当前 `0.3.0-dev` 场景中。本仓库整理阶段不改动建筑与美术内容。

## 模型细化

- 丰富店铺立面、橱窗陈列、屋檐、招牌和门口小物件。
- 继续补充住宅外墙、空调外机、公告栏及街道边缘细节。
- 按既有画面风格统一几何比例、轮廓和材质层次。

## 街区扩展

- 完善便利店、网吧和酒吧之间的巷道连接与空间导向。
- 为街道转角、停车区域和店铺入口增加更清晰的空间层次。
- 在保持场景紧凑的前提下评估增加社区店面或住宅细节。

## 光影与氛围

- 调整招牌、窗光、路灯和湿地反射的平衡。
- 细化雨滴密度、雨夜能见度与积水高光表现。
- 检查不同屏幕尺寸和画面比例下的初始镜头构图。

## 性能与维护

- 分析单页源码和渲染负载，评估材质复用、几何合并及阴影开销。
- 为低性能设备提供更合适的像素比、雨滴数量和阴影设置。
- 在不改变当前默认运行方式的前提下评估代码分段与资源管理方案。
- 每次影响渲染或交互的调整后复查旋转、缩放和平移操作。
