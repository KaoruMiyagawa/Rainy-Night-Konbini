# 开发记录

## 记录范围

项目目录最初没有 Git 历史或独立源码拆分。以下过程根据现存的 `index.html`、分享包说明和场景截图归纳，只记录能够从当前交付物辨认的功能；阶段顺序是按场景扩展关系整理，不代表可验证的时间线或提交顺序。

## 场景演进

### 便利店主题

项目以雨夜中的日式便利店为视觉核心，使用内嵌的 Three.js 场景、灯光、材质和雨滴动画呈现夜间街角。店铺橱窗、招牌、门前道路和积水反光形成场景主体。

### 街角环境

场景扩展出相邻街道和更多街角设施。当前画面可见路灯、架空电线、交通标线、斑马线、护栏、单车等街道细节，强化了道路转折和社区氛围。

### 网吧与酒吧

随后加入网吧与酒吧立面，使便利店周围成为具有营业空间层次的夜间街区。分享包中同时提供了全景截图和酒吧近景截图，佐证这些建筑已纳入当前场景。

### 单文件交互场景

当前交付以根目录 `index.html` 为运行入口，将 Three.js r180 与 OrbitControls 代码一起打包在页面中。页面可本地打开，并支持旋转、缩放和平移相机；无需外部网络资源或安装项目依赖。

### 仓库基线

本次整理建立版本号 `0.3.0-dev`，补充 README、变更日志、后续路线和第三方声明，并进行浏览器渲染及鼠标交互验证。该节点是首个 Git 基线，并非原项目的起始时间。
